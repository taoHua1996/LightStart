# LightStart 0.4.1

Fix automatic skipping for startup ads with countdown labels such as `跳过｜5` and `Skip | 5`. Previously, the separator prevented an otherwise valid skip button from matching.

Handle an initial splash ad followed by a second startup popup within the original 12-second window. The second action requires a different verified skip-button resource ID and a one-second cooldown after an accepted first click. A session permits at most two attempts; rejected actions and missing verified IDs prevent further attempts. Existing label, position, package and bounds checks remain in place.

## Downloads

- **LightStart-0.4.1-local-debug.apk** uses the same signing key as the locally installed 0.4.0 and 0.4.1 builds. Choose this asset to update those installations.
- **LightStart-0.4.1-debug.apk** is built by GitHub Actions. Its debug signing key may differ from local and previous CI builds.
- SHA-256 checksum files accompany the APKs. Android 8.0 or later is required; the app interface is in Simplified Chinese.

Different signing keys prevent in-place updates. Uninstalling removes local settings and statistics.

## Validation

93 core policy assertions passed. APK signature verification passed; Android Lint reported zero errors and two existing warnings. Physical-device recording on Android 16 confirmed that Anime Republic's initial splash ad and subsequent startup popup both closed while their countdowns still displayed 5, without manual ad taps.

See [validation details](0.4.1-validation.md). This change does not intercept shake-triggered redirects; motion-sensor restrictions are a separate system setting. Ads outside the startup window or without accessible skip controls remain outside the supported behavior.
