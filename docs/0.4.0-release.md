# LightStart 0.4.0

## Changes

- Automatically learn package-qualified skip-button IDs after accepted clicks. Recognize exact skip labels in the upper-right and lower corners, with text fallback when no ID is available. Manual rules retain priority, and learned IDs still require a safe current label and position.
- Add a Settings tab with controls for ID learning, foreground background protection, and optional restoration after boot.
- Show a persistent protection notification with a stop action. Stopping protection persists across app reopening and reboot. Closing the activity does not intentionally stop protection.
- Add shortcuts to notification, battery and system autostart settings, with fallback guidance when a system page is unavailable.

## APK downloads

- **LightStart-0.4.0-local-debug.apk**: locally built and signed with the same key as the 0.4.0 APK installed during physical-device testing. Choose this to update that installation.
- **LightStart-0.4.0-debug.apk**: built by GitHub Actions. Its debug signature may differ from local and previous CI builds.
- Checksum files accompany both APKs. Android 8.0 or later is required. The interface is in Simplified Chinese.

Different signing keys prevent an in-place update. Uninstalling removes app settings and statistics; preserve any needed data before switching signing tracks.

## Validation and limits

71 core policy assertions and 8 Android preference assertions passed. Android Lint reported zero errors and two warnings. Emulator tests covered safe ID reuse, task removal, boot recovery and persistent notification stop. On an Android 16 phone, installation, accessibility binding and foreground protection were verified; the demo and Xiaocan recorded accepted click actions.

Accepted clicks are not proof of visual ad dismissal. Physical-device OEM autostart permission and reboot recovery remain unverified. Force-stop, the Android task manager and some system cleaners can stop the app; background protection cannot guarantee an immortal process.

See [full validation results](0.4.0-validation.md).
