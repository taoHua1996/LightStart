# 安卓手机使用与验收

轻启面向各品牌安卓手机，不限定机型或厂商系统。最低支持 Android 8（API 26）。授权、后台运行和电池管理的入口可能随设备与系统版本变化；请以手机实际显示的选项为准。系统更新到最新版不等于所有广告与后台场景都已经验证通过。

## 首次设置

1. 安装轻启，在概览阅读披露并进入无障碍设置，手动启用“轻启 · 开屏跳过”。
2. 如果提示受限设置，在轻启的系统应用详情菜单查找“允许受限设置”；仅在确认安装包来源后操作。不同系统版本可能采用不同提示。
3. 返回轻启，在应用页点击“一键启用”，或单独开启需要处理的应用；默认识别无需逐个填写规则。
4. 回到概览确认无障碍已连接、总开关已开启且已启用应用数大于零，再运行演示并查看记录。从桌面打开已启用应用验证实际效果。

## 后台设置

不同安卓手机提供的选项和名称可能不同。优先使用系统设置搜索；找不到某项时，可查看轻启的系统应用详情或电池设置：

- 如果系统提供“自启动”选项，按需允许轻启自启动。
- 搜索“后台运行”或“电池优化”，按需将轻启设为允许后台运行或对应的“不限制”选项。
- 如果最近任务支持锁定应用，可按需锁定轻启，降低一键清理时被结束的概率。
- 轻启的“打开轻启应用设置”和“打开电池优化设置”提供通用入口；具体开关需由用户手动确认。

这些设置不是保活保证。强行停止、关闭无障碍、系统安全策略和省电策略仍可能使功能失效。

## 必测项目

分别测试一次：正常打开目标应用、切回后台再打开、锁屏后解锁、一键清理后打开、重启手机后打开。每次先看轻启的服务连接状态，再检查实际跳过动作和记录。重启通知时间不代表服务已恢复。

如果无效，记录 Android 版本、手机系统版本号、目标应用名称与版本，以及按钮文字/出现位置。没有可访问控件的开屏页可能无法支持；摇一摇跳转也不属于可全面阻断的能力。
