# LightStart 0.4.1 validation

## Problem and change

On an Android 16 physical phone, Anime Republic (`com.shizi.tool.p3`, app version 1.0.0.7) exposed a splash button labeled `跳过｜1`. The previous exact-label matcher rejected the full-width separator. A second startup popup also remained because the previous foreground session allowed only one click attempt.

The matcher now accepts a single ASCII or full-width vertical separator between an exact skip label and a one- or two-digit countdown. Unrelated text, extra separators and download labels remain excluded. Visibility, enabled state, package, position and clickable-ancestor bounds checks remain in place.

A foreground session now permits up to two attempts inside its original 12-second window. A second attempt requires an accepted first action with a verified package-qualified ID, a different verified ID, and a one-second cooldown. Rejected clicks and missing verified IDs stop further attempts. The startup deadline never extends.

## Verification

- 93 core policy assertions passed, including separator matching, ambiguous-label rejection, second-ad cooldown, duplicate-ID rejection, the two-attempt limit and the unchanged deadline.
- APK build and signature verification passed. Android Lint: zero errors, two existing warnings.
- The final 0.4.1 APK (version code 9) was installed as an in-place update on the physical phone.
- A diagnostic UI tree identified `tobid_splash_skip_text` and `tobid_interstitial_skip_text`, each with a small clickable parent. UI-tree inspection was separate from the final automatic-skip test, because UI Automator can temporarily suppress accessibility services.
- During the final 16-second screen recording, no manual ad taps or UI Automator inspection ran. The splash ad was visible at approximately 4.50 seconds with countdown 5 and was gone by 4.75 seconds. The second popup was visible around 7.21 seconds with countdown 5 and was gone by 7.25 seconds. Two new accepted click events corroborated the recording.
- Private recordings and device data remain outside version control. The temporary diagnostic application was uninstalled.

These results cover the observed ad formats on that device. Ads that lack accessible controls, appear outside the startup window, or exceed the two-attempt limit are not covered. Disabling motion-sensor access to prevent shake-triggered redirects is a separate system setting, not an ad-skip action performed by LightStart.
