# 设备验收清单

未执行的设备项目不得视为通过；构建通过不等于真实 APP 的广告兼容性已验证。

| 项目 | 操作 | 预期 |
| --- | --- | --- |
| 安装与首次启动 | 安装 APK，打开轻启 | 没有三方应用默认开启，没有统计造数 |
| 未授权 | 进入演示页 | 不自动点击，手动跳过不生成服务记录 |
| 手动授权 | 从轻启同意披露，进入系统打开无障碍 | 回到概览显示已连接，或明确显示等待系统 |
| 演示 | 点击“测试跳过功能” | 自动移除模拟页，新增一条演示提交记录，累计仍为 0 |
| 暂停 | 关闭启用开关后进入演示 | 不执行点击 |
| 单应用 | 开启目标应用，从桌面启动 | 仅符合位置/文字/面积规则的按钮可能被点击 |
| 白名单 | 关闭同一应用后再次打开 | 不再点击 |
| 超时与重复 | 在同一应用停留 >12 秒；触发界面刷新 | 不延长扫描，不重复点击 |
| 自定义规则 | 填写正确/错误 ID 与文字 | 两项需同时满足，无泛化回退 |
| 锁屏 | 扫描期间锁屏 | 不执行后台点击 |
| 系统界面 | 打开设置、输入法、拨号、桌面 | 不自动点击 |
| 数据持久性 | 重启轻启，再重启手机 | 统计/规则仍保留；服务是否恢复如实显示 |
| 清理任务 | 从最近任务移除轻启后测试目标应用 | 分品牌记录是否仍有效，不预设结果 |
| 强行停止 | 应用设置中强停轻启 | 不宣称仍有效；重新打开并检查服务 |
| 撤权 | 系统关闭无障碍后回到轻启 | 显示未开启，停止点击 |
| 数据删除 | 确认清空统计 | 记录及聚合清零，应用规则保留 |
| 字体 / 深色 | 1.3 倍字体，深色主题，旋转 | 文字可读、控件可滚动触达、不被系统栏遮住 |
| 无网 | 飞行模式执行演示 | 所有本地功能可用 |

优先覆盖 Android 8、13、16，以及目标厂商的一台真机。模拟器无法代表厂商后台和广告 SDK 行为。
