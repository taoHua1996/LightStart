# 轻启 0.3.0

## 名称与工程

- 应用名称、权限说明、无障碍服务标签和返回按钮统一为“轻启”。
- 英文及项目文件夹名称为 `LightStart`，宣传语为“少等一会，轻松打开。”
- 保留原安卓安装标识、服务组件及数据名称，支持相同签名下覆盖安装并继承配置。
- 新增 MIT 许可证、贡献说明、打包脚本及 GitHub Actions 工作流。
- 每次推送自动构建 APK；版本标签通过构建后发布 Release APK 和校验文件。

## 本地验证

2026-10-24：

- `tools/package.ps1` 执行完成，APK 构建、Lint 和 v2 签名校验通过。
- 核心策略回归：39 项断言通过。
- 在 MuMu Android 12（API 32）覆盖安装成功；应用显示“轻启”和新宣传语。
- 原有 11 个启用应用及累计统计保留；新版本演示自动跳过，新增 `accepted / demo=1` 记录，第三方累计不增加。

本地 APK 位于 `releases/LightStart-0.3.0-debug.apk`。APK 不提交源码仓库，通过 Releases 或 Actions Artifacts 分发。

模拟器验证不代表所有安卓手机、厂商后台策略或真实广告都兼容。当前版本使用调试签名；连续覆盖升级还要求签名一致。

## 0.3.1 构建环境修正

首次云端构建发现 SDK 初始化步骤默认请求已移除的 `tools` 包。0.3.1 明确只安装 `platform-tools`，并固定 Ubuntu 24.04 构建环境、更新 Java 初始化步骤。功能与 0.3.0 一致，版本号递增以支持覆盖升级。
